# ListaRota

Aplicação Android nativa em **Kotlin + XML (Material 3)** para organização diária de paragens, visitas técnicas ou entregas.

- **Package / Application ID**: `pt.carlosgoncalves.listarota`
- **Privacidade**: 100% local e offline-first (`SharedPreferences` + JSON nativo `org.json`). Sem servidores externos, sem chaves de API e sem permissão `INTERNET`.
- **Requisitos**: Android Studio Jellyfish / Koala ou superior, JDK 17, Android SDK 34 (`minSdk 24`).

## Como compilar

1. Extraia o ficheiro `.zip` para uma pasta local.
2. Abra a pasta raiz `ListaRota` no **Android Studio** (*File > Open*).
3. Aguarde a sincronização do Gradle e execute em emulador ou dispositivo Android (`Run 'app'`).
